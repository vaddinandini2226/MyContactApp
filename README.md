# MyContactApp

MyContactApp is a Java-based console application that helps users manage their contacts efficiently. The project is developed by implementing Object-Oriented Programming (OOP) concepts, Java features, and various Design Patterns through different use cases.

## Features

- User Registration
- User Authentication
- Profile Management
- Create Contact
- View Contact
- Update Contact
- Delete Contact
- Bulk Contact Operations
- Search Contacts
- Filter Contacts
- Contact Tag Management
- Assign Tags to Contacts

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/vaddinandini2226/MyContactApp.git
```

2. Open the project in Eclipse.

3. Navigate to:

```
src/mycontactapp/
```

4. Run the `UserRegistration` class.
