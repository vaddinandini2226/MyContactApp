# 📒 MyContactApp

MyContactApp is a Java-based console application developed to demonstrate real-world Contact Management System functionalities while applying Object-Oriented Programming (OOP) principles, Java concepts, and Design Patterns.

The project is organized into multiple Git branches, where each branch focuses on implementing a specific use case or feature. This approach follows a structured development workflow similar to real-world software development.

---

# 📌 Project Overview

MyContactApp allows users to manage their contacts efficiently by providing features such as:

- User Registration
- User Authentication
- Profile Management
- Contact Creation
- Contact Viewing
- Contact Updating
- Contact Deletion
- Bulk Contact Operations
- Contact Search
- Contact Filtering
- Contact Tag Management
- Tag Assignment

The project emphasizes clean object-oriented design, modular implementation, and the practical use of Java Design Patterns.

## 🔹 Feature Branches

Each feature branch contains the implementation of an individual use case before it is merged into the `dev` branch.

Examples:

- feature/user-registration
- feature/user-authentication
- feature/profile-management
- feature/create-contact
- feature/view-contact
- feature/update-contact
- feature/delete-contact

Feature branches help in isolated development and easier code management.
